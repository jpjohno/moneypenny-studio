# JJRVIS pilot readiness — 20 October 2026

This is a release review and proposed acceptance plan, not a sales-readiness certificate.

## Product promise to prove

One assistant that can find a document, explain it, prepare useful work and show the evidence behind its actions. JJRVIS owns the tool and permission boundaries; Moneypenny is one configurable presentation. An attractive globe is decoration, not evidence of live device coverage.

The first pilot should remain James's own Mac and phone. Do not promise whole-computer control, every social account, every office app, photographic avatars or a customer-ready autonomous agent. The present code does not prove those claims.

## What this release adds

| Journey | Implemented behaviour | Remaining acceptance |
| --- | --- | --- |
| Find a downloaded document | Fresh Spotlight search in Documents, Desktop and Downloads; owner-only result IDs | Check one real Word, Excel, PDF and Numbers document; cloud-only and unindexed content can be absent |
| Read a document | Bounded read-only text extraction for DOCX, XLSX, PPTX and text; PDF/image viewer | Verify representative layouts; formulas, macros, OCR and native Numbers extraction are not implemented |
| Ask about it | Select a text preview, prepare a question, then explicitly submit using the selected AI | Check answers against source passages; configured cloud AI may process selected text |
| Open an original | Explicit request to the default Mac app; installed-app catalogue | A launch request is not proof of editing, saving or completing a workflow |
| Social and YouTube access | Named website launchers | Separate OAuth/provider adapters are needed for account reading, publishing, messaging and revocation |
| Voice map request | Owner confirmed spoken map command; native UI showed map and acknowledgement | Repeat ordinary questions and interruption tests; configured transcription can use cloud services |
| World display | Higher-resolution accelerated static Earth with coordinate and fallback tests | Review on older Macs, iPhone and sustained use with speech |
| Moneypenny appearance | Existing configurable clothed CG rig and corrected fabric | Hair/source asset quality and redistribution licence review still block photographic commercial presentation |

## Small pilot gates

1. Complete 30 useful requests covering speech, search, selected-file questions and a supported device. Record success/failure and time to first useful result. Do not invent a score before running them.
2. Complete five real documents in each supported file family. Check preview, native open, cancellation, missing file and permission-denied behaviour. Keep originals unchanged until an explicit edit workflow is tested.
3. Test one supported camera and one home device with owner permission, freshness timestamps, revoke/off behaviour and confirmed device receipts. Saved profiles are not live tracking.
4. Test sign-in expiry, Stop, phone permissions, data export and cross-household rejection before another household receives real account access.
5. Finish asset licensing, Apple distribution/signing, backup restoration and support diagnostics. Development-signed local builds are not a customer distribution channel.

## Business decisions

Start with a small concierge service pilot whose offer names exactly which workflows and devices are supported. Measure setup time, support minutes per household, API cost per completed request, repeat weekly use and failures requiring human intervention. These determine an affordable service model; no revenue, profit, valuation or market demand is established by this prototype.

Offer appearance and voice choices without gender assumptions. A compact orb and a text-only accessible mode should perform the same underlying tasks. Make the assistant optional to view, and keep Stop and privacy controls easy to reach.

Any autonomous work should begin with bounded, reversible draft tasks and a visible queue of what was proposed, attempted and verified. Messaging, trading, payments, destructive changes and access expansion retain their separate explicit authorisation. Adding more tools is justified when a tested user journey needs them, with a clear disconnect path.

## Free source-asset review

The current local Vitruvian-derived hair atlas and 2048 px export were inspected. Earlier blonde remapping narrows strand contrast; the source card arrangement, facial styling and cloth remain visibly CG. No new character replacement passed photographic acceptance in this update. Keep the current source and morph/voice contract intact while comparing a new source; texture resolution or render count alone is not an acceptance test.

Renderpeople advertises free scanned rigged models with skinned skeletons and high-resolution maps ([free downloads](https://renderpeople.com/free-3d-people/)). Its [published terms](https://renderpeople.com/general-terms-and-conditions/), section 4.2(c), restrict inclusion in certain applications where third parties use the data without separate consent; section 4.3 also restricts extractable asset distribution. These are reasons to resolve permission before choosing this as the JJRVIS customer asset, rather than treating free download as an unrestricted SaaS licence. No asset was downloaded, purchase made or licence accepted.
