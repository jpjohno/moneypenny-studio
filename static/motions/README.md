# Included motion studies

`studio-bow.motion.json` and `studio-stretch.motion.json` are small authored relative-joint studies. `studio-wave.glb` is a self-authored IK wave baked/exported by `scripts/character/export_wave_study.py` from the local Blender workshop. Its carrier mesh is only a tiny skeleton container; the person is not duplicated in this file.

The source rig comes from the CC0 MPFB sample attributed in the main README and assets manifest. No Adobe/Mixamo or commercial motion-library animation is bundled. These are working pipeline studies, not a claim of professional motion capture, collision-safe dressing or completed photoreal anatomy.
